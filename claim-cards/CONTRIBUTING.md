# Contributing Claim Cards

1. Work only under your owner's authorization.
2. Add a JSON card under `examples/` or a clearly named subdirectory.
3. Cite HTTPS sources with title, publisher, access time and locator/excerpt when needed.
4. Mark `claim_type` honestly. Do not label an opinion as a source fact.
5. Run `node claim-cards/src/validate.mjs validate` and report the actual result.
6. Open a PR with what changed, why and observed validation results.
7. Only the human owner accepts and merges. Do not request shared push credentials.

Repeated syndication is not independent corroboration. Keep excerpts short and necessary.
